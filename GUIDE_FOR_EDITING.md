# VIVA — карта проекта для самостоятельных правок

## Быстрый старт

В Render используй **Python**, `pip install -r requirements.txt` и команду
`uvicorn main:app --host 0.0.0.0 --port $PORT`.

## Что где менять

| Файл | Назначение |
|---|---|
| `index.html` | HTML-контейнеры интерфейса и загрузочный экран |
| `style.css` | **ЕДИНСТВЕННЫЙ CSS**, включая редизайн Ocean Glass в конце |
| `app.js` | Экраны игры, обработчики нажатий, анимации, API-запросы |
| `main.py` | FastAPI, запуск бота, статические файлы, API |
| `config.py` | Настройки окружения и важные параметры |
| `db.py` | База данных и её схемы |
| `fishing.py`, `fishing_engine.py` | Рыбалка и её серверная логика |
| `admin.py` | Админ-панель на сервере |
| `botapp.py` | Telegram-бот |
| `auth.py` | Проверка авторизации Telegram — **не отключай** |
| `community.py` | Общий чат |
| `catalog_v*.py`, `features_v11.py`, `v14.py` | Каталог и игровые механики нескольких версий |
| `assets/` | Рыбы, иконки и другие изображения (без изменений) |

### Изменить цвета

Ищи `:root` в `style.css`. Внизу этого файла находится блок
**«РЕДИЗАЙН OCEAN GLASS»** с окончательными правилами. Изменения лучше делать
в нём, а не в старых правилах выше. Например, `--bg` задаёт цвет фона,
`--t` — цвет текста, `--sea` — голубой акцент.

### Изменить экран или кнопку

Ищи названия функций в `app.js`: `fishView`, `bagView`, `shopView`,
`profileView`, `menuView`, `paint` и `go`. Используется историческое
расширение функций: новые версии внизу `app.js` оборачивают старые.
**Не переставляй эти блоки без понимания зависимостей.**

### Изменить игровые шансы или награды

Меняй серверный Python-код, а не только цифры в интерфейсе. Сначала найди
механику в `fishing.py`, `features_v11.py`, `v14.py` и каталогах.

## Что было сделано

- `redesign.css` объединён со `style.css` с сохранением порядка правил.
- `index.html` подключает только один CSS-файл.
- Добавлены поясняющие комментарии в JS, HTML и Python.
- Игровые обработчики, API, база данных и `assets/` сохранены.
- Убраны только лишние CSS-файлы, **версионные Python-модули не удалены**,
  потому что могут использоваться действующими маршрутами.

## Проверка перед релизом

Проверь в Telegram рыбалку, кейсы, рюкзак, чат, профиль и админ-панель.
Проверка синтаксиса не заменяет функциональное тестирование с живой БД.
