# Viva 2.0 — первый перенос макетов Figma

Изменения: новый файл `viva2.css`; дополнительные функции рендеринга в конце `app.js`; разрешена отдача стилей в `main.py`; `index.html` подключает новые стили.

Обновлены: рыбалка, верхний профиль с кольцом прогресса, нижняя навигация, меню кейсов и страница кейса. Экран рюкзака получил оформление двухколоночной коллекции на базе существующих карточек. Награды и суммы рассчитываются прежним сервером.

Графика локаций использует существующие SVG-пейзажи Viva, а не новые фотографии: для точной замены нужны утверждённые изображения. Протестировать отображение в Telegram и на реальных устройствах необходимо отдельно.

## Запуск

Установить зависимости из requirements.txt, задать BOT_TOKEN и WEBAPP_URL (см. README), затем `uvicorn main:app --host 0.0.0.0 --port 8000`. Не публикуйте локальную базу данных и секреты. Для чисто визуального просмотра требуется авторизованный Telegram WebApp.
