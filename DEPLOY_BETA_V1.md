# Viva.Beta.V1 — инструкция для сервера

## 1. Перед запуском
- Установи Python 3.11 или 3.12 и зависимости: `python -m pip install -r requirements.txt`.
- На сервере задай секрет `BOT_TOKEN`, публичный HTTPS `WEBAPP_URL`, постоянный путь `DB_PATH`.
- Не загружай `.env`, токен и реальные файлы `database.db` в публичный репозиторий.
- Вставь существующую базу по `DB_PATH` **до запуска**. При старте схема дополняется новыми таблицами, данные не сбрасываются.
- Рекомендуется отдельный постоянный диск для SQLite, иначе после пересоздания контейнера могут исчезнуть данные.

## 2. Запуск
`uvicorn main:app --host 0.0.0.0 --port ${PORT:-8000} --workers 1`

Только один экземпляр polling Telegram-бота. Запуск нескольких процессов на одном токене вызовет `TelegramConflictError`.

## 3. Проверки перед открытием для игроков
1. Открой `https://YOUR_DOMAIN/health` и `https://YOUR_DOMAIN/health/db`.
2. Запусти `/start` от имени администратора Telegram ID 1181838335.
3. Проверь открытие всех экранов: рыбалка, рюкзак, кейсы, аквариум, Pass, Shop, чат, награды, админка.
4. Проверь 1 кейс, 3 кейса, отказ при полном инвентаре и продажу полученных снастей.
5. Проверь один заброс и получение результата, запись рекорда текущей локации.
6. Проверь 30 строк Pass и выдачу награды на тестовом игроке (сервер проверяет уровни и порядок).
7. Проверь резервное копирование через кнопку админки: бот должен прислать `viva-backup.db` в личные сообщения администратора.
8. Отдельно проверь тестовую оплату Telegram Stars и только затем разрешай реальные покупки.
9. Проверь блокировки чата, техработы по отдельным разделам и работу модератора.
10. Сделай реальную копию БД и сохрани отдельно от сервера.

## 4. Изменения этой сборки
- Исправлена раздача `v16.js`, `v16.css`, `v17.js`, `v17.css`, `v18.js`, `v18.css`, которые раньше сервер ошибочно возвращал с 404.
- Добавлена `viva_location_records` с записью редчайшей и самой тяжёлой рыбы в каждой локации.
- Изгиб удочки на Canvas и визуальная нагрузка теперь зависят от редкости добычи и фазы вываживания.
- Более долгие плавные анимации массового открытия и свечение редких карточек.
- Уточнено отображение содержимого наград Viva Pass на основе ответа API.
- Дополнительная типографика, контрастные состояния, фокус-контуры и настройки уменьшения анимации.

## 5. Ограничения
- Настоящие платежи, доставка резервных копий и все действия с Telegram **не тестировались** без токена и запущенного Telegram-бота.
- Нельзя открыть 10 кейсов с лимитом 5 предметов одной категории: сервер корректно отклонит операцию, не списав деньги. Это ограничение исходного правила рюкзака.
- Полное восстановление загруженной резервной копии требует остановки сервера, проверки целостности и ручного применения staged-файла.
- Анимированные силуэты аквариума декоративные; доход считается сервером.
