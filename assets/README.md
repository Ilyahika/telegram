# Game image assets

Generated using the built-in image-generation tool for this project. Not scientific species-reference photographs.

Prompt set: two studio product-photo texture atlases on a dark navy background, no emoji, no labels or text, separate row-major cells. Fish: 10 columns × 12 rows, species order from fishing.FISH. Lures: 8 × 8 cells, order from fishing.GEAR filtered to bait/spoon/spinner, followed by one spare silver hook. Realistic scales, fins, lure metal and silicone textures; fantasy finishes for mythical items. Precise cell rectangles are stored in catalog_v5.py.

Source atlas files are retained unchanged. The web client uses per-item cropping metadata; there are no external image requests.
