# Monster Islands — Portrait World V1.2

Полноэкранная вертикальная 2D-игра с псевдо-3D (объёмные пиксельные спрайты), настоящей тайловой картой 96×72, камерой, физическими препятствиями и тремя следующими за игроком существами.

## Запуск (Windows PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:DEV_DEMO="1"
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

Откройте http://127.0.0.1:8000, в вертикальном режиме. WASD, стрелки, джойстик или клик по земле. Кнопки «Меню» и «Строить».

## Telegram

Нужно `BOT_TOKEN` и публичный HTTPS `WEBAPP_URL`, запуск `python bot.py` отдельным процессом. В боевом окружении НЕ задавать `DEV_DEMO=1`.

## Текущее состояние

Работают серверная Telegram-авторизация, регистрация, кейсы, инвентарь, выбор спутника на время сессии, постройки и сохранение. Визуальная карта генерируется в браузере из тайлов; препятствия — вода, камни и деревья. Монстры представлены нарисованными отдельно PNG-спрайтами с объёмными светотенями; это **не настоящие 3D-модели**. Рынок и задания представлены заглушками. Сохранение выбора спутника между сессиями, серверная проверка коллизий строительства и полноценный мультиплеер — будущая работа. Для публичного размещения нужна PostgreSQL вместо SQLite и аудит игрового API.

## Портретная версия
Ориентация **не блокируется**; приложение рассчитано на вертикальный экран 390×844 и адаптируется к другим размерам. Это портретная переработка существующего Monster Islands V1.1, а не готовая интеграция присланного Phaser RPG Template. Для адаптации исходного движка шаблона потребуется перенос его сцен и карт в веб-сборку.
