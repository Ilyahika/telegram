## Что изменено в V13

- Встроены 54 цветные SVG-иконки Twemoji: эмодзи в меню и на кнопках выглядят одинаково на разных устройствах, без внешних загрузок. Условия использования — `assets/EMOJI_CREDITS.md`.
- Цветное меню: отдельный цвет и эмодзи у каждого раздела, карточка профиля и красивая кнопка поддержки.

- Три нижние вкладки сохранены. Основные игровые кнопки получили контрастные сплошные цвета: рыбалка — оранжевый, кейсы — фиолетовый, продажа — зелёный, аквариум — голубой. Кнопки не используют фон локации.
- Для 3, 5 и 10 кейсов добавлена короткая анимация: подарки переворачиваются в награды по очереди. Обычно она длится около 1–1,6 секунды; её можно пропустить. За один клик выполняется один запрос открытия. После анимации игрок остаётся внутри кейса.
- Ссылка поддержки сохранена: https://t.me/OKEY_VE. Текущие данные, фотографии, ловля и админка V12 сохранены.

Обновление Viva V11 на основе приложенного Viva V10. Python 3.10+; FastAPI, aiogram, SQLite.

## Установка и обновление

1. Сохраните резервную копию базы через `python backup_db.py backup-before-v11.db` из старой папки проекта. При обновлении работающего сервера сначала остановите старый процесс.
2. Замените файлы проекта содержимым папки `Viva` из архива. Сохраните существующую базу и переменные окружения.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Запустите: `python -m uvicorn main:app --host 0.0.0.0 --port 8000 --workers 1`.

Render Start Command: `python -m uvicorn main:app --host 0.0.0.0 --port $PORT --workers 1`.
Environment: `BOT_TOKEN`, `WEBAPP_URL` (HTTPS), `DB_PATH`. На Render публичный адрес автоматически берётся из `RENDER_EXTERNAL_URL`.

Для сохранения прогресса между пересозданиями Render нужен постоянный диск и путь `DB_PATH=/var/data/database.db`. Архив не содержит базы, токенов и тестовых пользователей. `.env.example` — образец переменных; само приложение читает переменные процесса, а не загружает `.env` автоматически. Один процесс polling: `--workers 1`.

Миграция запускается автоматически при старте и первом входе игрока. Балансы, опыт, коллекция и история остаются. Существующие стаки рыбы превращаются в отдельные экземпляры; веса берутся из доступной истории, при отсутствии истории — минимальный вес вида. Старые ID сохраняются; фантазийные названия рыб заменены реальными видами. Старые лески, вертушки и колебалки удалены как отменённые категории. Каждому игроку один раз добавляется базовая катушка. Старые предметы сверх лимита не удаляются: лимит применяется к новым наградам. Четыре старых категории кейсов преобразуются в новые, старые настройки состава сбрасываются один раз, поскольку состав и экономика изменились.

## Ловля и экипировка

- Максимум 5 попыток, +1 каждые 120 секунд. При полном запасе время не копится.
- Одна кнопка запускает автоматическое вываживание: 3,5 / 4 / 5 / 6 / 7,5 / 9 / 10 секунд. Награда определяется сервером и выдаётся только после таймера. Срывов, подсечки, управления натяжением и расходников больше нет.
- Анимация — стилизованная векторная сцена от третьего лица с рыбаком, удочкой, водой и эффектами редкости. Это браузерная анимация, не 3D-видео.
- Три слота: удочка, катушка, приманка. Все выбираются в рюкзаке. Каждый предмет даёт 0–15% удачи; суммарно до 45%. Удача увеличивает относительные веса редких исходов, не гарантирует определённую рыбу. Итоговые вероятности показаны на экране.
- Для локации нужны её уровень и грузоподъёмность каждого из трёх предметов не ниже максимального веса рыбы этой локации. Стартовый комплект подходит для пруда.
- 120 записей рыб, по 24 на локацию. Диапазоны веса — игровые ориентиры для реальных видов, а не точная биологическая база рекордов. Мелкие рыбы могут весить несколько граммов, крупные океанские — сотни килограммов. Цена экземпляра: базовая цена вида × фактический вес, округление до целого доллара.
- Редкости: Обычный, Редкий, Эпический, Профессиональный, Легендарный, Мифический, Секретный. Уникальный отображается как недоступный и не выпадает.

## Кейсы и цены

9 кейсов: три уровня арсенала × удочки / катушки / приманки. Составы различаются, категории не смешиваются. Можно открыть 1, 3, 5 или 10. Для одного — рулетка с центральной меткой или быстрый режим; несколько — с короткой анимацией появления наград. После открытия игрок остаётся внутри кейса. Бесплатные кейсы расходуются раньше долларов. За каждый кейс +35 EXP.

Рыночная стоимость предмета фиксирована, продажа всегда 50%. Базовые рыночные цены по редкости: 80 / 400 / 1800 / 6000 / 18000 / 60000 / 200000 долларов. Серии отличаются на 10% базовой цены; диапазоны соседних редкостей не пересекаются. Стоимость предмета никогда не зависит от кейса. Стоимости кейсов: 800 / 4000 / 18000. Низкая редкость приносит убыток относительно цены кейса, средняя близка к окупаемости в соответствующем арсенале, высокая может окупить открытие. Настройка цен и шансов администратором может изменить эту экономику.

Дубликаты хранятся как дополнительные экземпляры. При заполненных 20 местах экипировки новая награда автоматически продаётся за обычные 50%; это явно указано в результатах. Можно продать дубликат надетой снасти, последнюю надетую — после замены другой снастью.

## Подсак и аквариум

В подсаке 30 рыб, в аквариуме 5. У каждой рыбы отдельный ID, вес и цена. Карточки расположены по две в ряд. При активном вываживании для результата резервируется место.

Доход в час = цена экземпляра × (1,5% + 0,5% × индекс редкости), где индекс начинается с нуля. Накопление ограничено 5 часами после последнего сбора; первое заселение пустого аквариума без дохода запускает новый период. Состав аквариума можно менять; уже заработанное сохраняется, срок не продлевается. Забрать можно в любой момент, выплачивается целая часть, дробная сохраняется. Время и доход рассчитываются сервером, экран плавно обновляет сумму. После перезапуска и отсутствия игрока накопления сохраняются.

## Меню, профиль, администратор

Нижняя навигация: Рыбалка / Рюкзак / Кейсы. Меню открывается кнопкой справа в шапке: профиль, награды, промокоды, общий чат, рейтинги, помощь, поддержка `https://t.me/OKEY_VE`, донат (техработы).

Профиль: выбор аватара из набора, ник и цвет, статистика, коллекция, паспорт и префикс. Личные фото с устройства не загружаются. В рейтингах учитываются уровень, деньги либо лучший трофей (сначала редкость, затем вес). Префикс показан у ника; в профиле — отдельной табличкой.

Полная старая админка сохранена: статистика, игроки, баланс/опыт/предметы, кейсы, блокировки, клевер, журнал, режим техработ, сообщения и рассылка. Новые роли и промокоды: **Меню → Игроки и модерация**. Администратор открывает паспорт игрока, выбирает один префикс и флаг модератора. Там же создаёт промокоды с долларами, EXP, числом активаций и сроком. Каждый игрок активирует конкретный код только один раз. Модератору доступны только просмотр игроков и блокировка/разблокировка; полные API администратора закрыты серверной проверкой. Модератор не может заблокировать администратора. Авторизация остаётся через подписанные Telegram initData, `ADMIN_ID` сохранён из V10.

## Проверки

Разработка: `python -m pip install httpx`, затем `python -m unittest discover -s tests`.

Тесты используют временные базы, не запускают Telegram polling и проверяют попытки, таймеры, повторы запросов, экипировку, экономику, аквариум, кейсы, промокоды, права доступа, чат и сохранность данных. Базу production в тесты не передавайте.
