# Monster Islands — Chapter I: Ратуша и первый магазин

Портретная (вертикальная) Telegram Mini App RPG на FastAPI и Canvas с пиксельными спрайтами.

## Что реализовано
- Остров из тайлов, коллизии, камера, 4-направленные кадры анимации персонажа, монстры-спутники.
- Стартовое здание — ратуша; сбор серверного пассивного дохода: 2 монеты/мин, максимум 720 монет за 6 часов.
- Только три возводимых здания: магазин (бесплатно), экспедиция (450 монет) и дом друзей (300 монет). По одному каждого вида.
- Обязательное серверное обучение: 1) походить персонажем, 2) нажать ратушу, 3) разместить магазин.
- Кейсы (виртуальные монеты, без реальных платежей) доступны только после строительства магазина. Инвентарь, монстры и рынок сохранены.
- Экспедиция: 250 монет раз в час после строительства.
- Сохранение острова и прогресса в SQLite для локального тестирования. Для публичного Render необходимо перейти на постоянную БД PostgreSQL.
- Кнопка Telegram Web App в `bot.py`; подписанное initData проверяется FastAPI.

## Локальный запуск (Windows PowerShell)
```
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:DEV_DEMO="1"
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```
Открыть `http://127.0.0.1:8000`.

## Telegram
Указать `BOT_TOKEN` и `WEBAPP_URL=https://...`, отключить `DEV_DEMO`, запустить `python bot.py` **отдельным процессом**. Для боевого использования нужны HTTPS и постоянная БД. Секрет BOT_TOKEN не помещать в репозиторий.

## Ограничения
Это рабочая глава с пиксельными 2D-спрайтами и объёмной стилизацией, **не** 3D-модели. Дом друзей пока открывает приглашение, полноценного посещения друзей нет. Экспедиция пока одна с часовым кулдауном. Карта генерируется детерминированно; визуальные ассеты требуют художественной полировки. Проверяйте Telegram WebView на реальном телефоне.
