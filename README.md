# Monster Islands — Template Edition V1.3

Портретная игра с работающей тайловой картой, камерой, пиксельными персонажем и монстрами, кейсами, инвентарём, строительством, серверным рынком и Telegram Mini App. 

## Источник

Проект основан на сервере и игровой сцене Monster Islands V1.2. Из присланного Phaser RPG Template добавлены исходники сцен для будущего переноса и графические ресурсы `Perli.png`, `NPCs_1.png`, `modern_exterior.png`. Лицензия исходного шаблона — MIT, текст в `THIRD_PARTY_LICENSE.txt`. **Текущая игровая сцена использует собственный Canvas-рендерер, не Phaser**. Это честная промежуточная рабочая сборка, а не готовый порт движка шаблона. Перед публикацией проверьте лицензирование отдельных игровых ассетов.

## Запуск в Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:DEV_DEMO="1"
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

Браузер: http://127.0.0.1:8000

Для Telegram: выставьте BOT_TOKEN и WEBAPP_URL (публичный HTTPS), отключите DEV_DEMO, запустите `bot.py` отдельным процессом. Не публикуйте токен в GitHub. В Render Free/обычных эфемерных файлах SQLite-данные теряются; для продакшена нужен PostgreSQL.

## Возможности и ограничения

Карта, ходьба, препятствия, 3 спутника, клиентский игровой экран, покупка построек, кейсы и рынок монстров. Выбор основного спутника сохраняется. Деньги и рынок проверяются сервером, одна покупка — одна транзакция. Для полноценного релиза нужно доработать совместное сохранение карт, серверную проверку допустимых строительных клеток, защищённую логику заданий и устойчивое хранилище PostgreSQL. 2.5D здесь означает 2D с объёмной пиксельной светотенью, а не настоящие 3D-модели.
