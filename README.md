# Monster Islands · First Release (2D pixel-style)

Переработанная версия Monster Islands v0.2: полноэкранный игровой мир в пиксельном стиле с глубиной, персонажем, монстром-спутником, анимированным перемещением, постройками, инвентарём и четырьмя кейсами. Арт острова взят из выбранной концепт-визуализации и используется в качестве фоновой сцены; **это не редактируемая тайловая карта**. Персонаж/монстры являются 2D-спрайтами поверх сцены, а не полноценными 3D-моделями. Такой подход нужен для первого проверяемого релиза.

## Windows / локальный запуск

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:DEV_DEMO="1"
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

Откройте http://127.0.0.1:8000 . Для проверки API: http://127.0.0.1:8000/docs .

## Telegram

Создайте бота через @BotFather. Укажите в переменных окружения `BOT_TOKEN` и `WEBAPP_URL` (публичный HTTPS адрес приложения). **Никогда не публикуйте BOT_TOKEN в GitHub**. Запустите сервер `uvicorn main:app --host 0.0.0.0 --port 8000` и отдельно процесс `python bot.py`. Бот создаёт кнопку Mini App в ответ на `/start` (WebApp-кнопку следует открывать в личном чате).

Для **публичного сервера** `DEV_DEMO` должен быть `0` (по умолчанию), иначе API позволяет играть без Telegram-подписи. Проверка Telegram `initData` выполняется сервером. Пользовательские данные хранятся в SQLite базе `monster_islands.sqlite3`. На бесплатных/эфемерных файловых системах Render эта база **может пропасть при деплое или рестарте**; для реального релиза требуется PostgreSQL или постоянный диск.

## Реально работает

- Подтверждение Telegram initData, автосоздание профиля.
- Вывод монет, 20 типов монстров, 4 кейса с указанными шансами, серверная выдача и инвентарь.
- Выбор монстра-спутника (выбор хранится только в текущей сессии UI).
- Персонаж перемещается касанием, WASD, стрелками и джойстиком.
- Позиция игрока и декоративные постройки сохраняются в базе по игроку.
- Декоративное строительство: дерево (бесплатно), сад (120 монет), фонарь (60 монет), максимум 25 объектов.

## Пока не реализовано

- Рынок игроков, полноценные интерактивные коллизии, тайловый редактор, симуляция добычи/заданий, мультиплеер, анимационные spritesheets, PostgreSQL миграция.
- Интерактивные здания на фоновой иллюстрации — это часть картинки. Новые постройки появляются как отдельные 2D-объекты поверх неё.

Все валюты исключительно игровые. Случайные кейсы не продаются за реальные деньги.
