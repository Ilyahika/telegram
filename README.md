# Monster Islands V0.2 🏝️🐲

Рабочая вторая итерация первой страницы: остров, уникальные SVG-модельки и портреты 20 монстров, инвентарь, 4 кейса, регистрация через Telegram, реальная серверная проверка initData, хранение монстров и баланса в SQLite. Данные сохраняются после перезапуска. Смена на PostgreSQL — следующий этап.

## Локальный запуск (Windows PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:DEV_DEMO="1"
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

Открой http://127.0.0.1:8000 — только в деморежиме `DEV_DEMO=1`. Получишь 1200 монет при первой регистрации. Данные тестового пользователя сохраняются в `monster_islands.sqlite3`. Для сброса тестового профиля останови сервер и удали этот файл.

## Telegram Mini App

1. В Telegram через @BotFather создай бота (`/newbot`), запомни токен. Никому его не отправляй.
2. Выложи сайт на сервер с **публичным HTTPS URL**. Адрес `localhost` в Telegram Mini App не подходит.
3. Настрой две переменные окружения на сервере: `BOT_TOKEN=<секретный токен>`, `WEBAPP_URL=https://твой-домен`. Не устанавливай `DEV_DEMO=1` в публичном проекте.
4. Для сервера FastAPI: `uvicorn main:app --host 0.0.0.0 --port ${PORT:-8000}` (для Linux, например Render).
5. Отдельным процессом запусти Telegram-бота: `python bot.py`. Бот по команде `/start` отправляет Web App кнопку.
6. При открытии через Telegram Mini App браузер отправляет подписанные `initData` в заголовке `X-Telegram-Init-Data`; сервер проверяет подпись и время. Клиентские `initDataUnsafe` для авторизации не используются.

**Важно:** Если запускаешь в Render, FastAPI Web Service и Telegram polling-бот должны работать как два отдельных процесса/сервиса. Бесплатное эфемерное файловое хранилище не подходит для постоянной SQLite: выбери устойчивый disk или переведи проект на PostgreSQL до публичного запуска. `/api/health` используется для проверки работоспособности.

## Что есть

- `main.py`: FastAPI, регистрация, кейсы, инвентарь, SQLite-транзакции, проверка Telegram initData.
- `bot.py`: aiogram `/start` с кнопкой Mini App.
- `static/index.html`, `style.css`, `app.js`: существующий остров и управления.
- `static/upgrade.js`: рабочие экраны кейсов, инвентаря, профиля.
- `static/monsters/`: **40 уникальных SVG**, по две графики (`-icon.svg`, `-portrait.svg`) на каждого из 20 монстров. Векторные картинки масштабируются без потери качества; `-icon.svg` используется на карте как моделька спутника. Это стилизованные иллюстрации, не реалистичные фотографии.

## Безопасность и границы V0.2

- Открытие кейса и списание монет происходят одной транзакцией на сервере. Не доверяем балансу/результату от клиента.
- Шансы по редкостям видны до открытия, а внутри редкости отдельные монстры выбираются равновероятно.
- Все кейсы только за **бесплатно заработанную внутриигровую валюту**; покупок случайных наград за реальные деньги и вывода денег нет.
- Нет пока рынка, достижений, продуманного источника дохода монет, PostgreSQL, нескольких следующих спутников и анимаций их индивидуальных модельных частей. База и API рассчитаны на дальнейшее расширение.
- В данном учебном проекте `DEV_DEMO` допустим только локально, поскольку разрешает тестовую авторизацию без Telegram. Не включай в публичной среде.
